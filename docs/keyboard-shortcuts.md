# Harbor keyboard shortcuts

Open the in-app shortcut reference from the **Keyboard shortcuts** button in the sidebar. The
reference automatically shows Command symbols on macOS and Ctrl/Alt labels on Windows and Linux.

| Action                                          | Windows and Linux             | macOS                |
| ----------------------------------------------- | ----------------------------- | -------------------- |
| Focus message search                            | `Ctrl + K`                    | `⌘ K`                |
| New message                                     | `Ctrl + N`                    | `⌘ N`                |
| New post                                        | `Ctrl + Shift + N`            | `⌘ ⇧ N`              |
| Open Settings                                   | `Ctrl + ,`                    | `⌘ ,`                |
| Show shortcut reference                         | `Ctrl + /`                    | `⌘ /`                |
| Close or cancel the open overlay                | `Esc`                         | `Esc`                |
| Send a message                                  | `Enter` or `Ctrl + Enter`     | `Enter` or `⌘ Enter` |
| Add a line to a message                         | `Shift + Enter`               | `⇧ Enter`            |
| Messages, Wall, Feed, Boards, Network, Settings | `Ctrl + 1` through `Ctrl + 6` | `⌘ 1` through `⌘ 6`  |
| Previous or next primary page                   | `Alt + ←` / `Alt + →`         | `⌥ ←` / `⌥ →`        |

Global shortcuts do not run while focus is in an input, text area, select, content-editable region,
or screen-reader textbox. Two deliberate exceptions apply:

- `Esc` can dismiss the current modal or transient overlay without changing entered text.
- Message composer shortcuts are handled by the composer itself: Enter sends, while Shift+Enter
  inserts a line break.

Harbor also preserves the conventional `Ctrl/Command + F` find shortcut in an open conversation
when focus is not already in an editing control.
